I developed a React Native application called Teams as part of my study and practice.
Here’s a brief summary of the features and technologies I used:

✨ Design System: Implemented using CSS-in-JS with Styled Components.
📂 Path Mapping: Improved project structure for better readability and maintainability.

🌐 Navigation: Seamless navigation between pages using React Navigation.

💾 Local Storage: Using AsyncStorage to store important information, ensuring that teams and players created by the user are saved even if the app is closed.

🔤 Custom Fonts and Icons: Fonts from Google Fonts and icons from the Phosphor Icons library, adding a unique touch to the application's design.

This project has been a great opportunity to deepen my knowledge of React Native and enhance my development skills. I'm looking forward to applying these concepts in future projects!
